# Beginner Cube Solver

Dies ist ein einfacher Rubik's Cube Solver, der die Anfängermethode (Layer-by-Layer) verwendet.  
Alle Algorithmen sind in `algorithms.yaml` gespeichert und werden Schritt für Schritt ausgeführt.

## Starten

```bash
python main.py
```

Die `Cube`-Klasse simuliert den Würfel, und der `BeginnerSolver` verwendet vordefinierte Schritte aus der YAML-Datei.
